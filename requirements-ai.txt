# Exact optional runtime set for BOTH in-process AI agents.

# These versions are the Python 3.12/3.13 set validated by the MAT safety stack.
# Both agents are independently opt-in and default-OFF (SL_HUNTING_ENABLED,
# CPR_AI_ENABLED), but they run inside the SAME master process, so Python can
# only ever install ONE version of the packages they share. Keeping them in one
# file makes that constraint structural instead of a comment two files apart --
# previously `mcp` and `pydantic` were pinned twice and had to be kept equal by
# hand, which is a silent-breakage waiting to happen.

# -- Shared by both agents ----------------------------------------------------
# These are the packages that forced the merge: one process, one version.
#
# HELD AT 1.x DELIBERATELY. Dependabot proposed mcp 2.1.1 in PR #151 and CI
# refused it with a real breakage, not a policy failure: 2.x removes

# that server plus a re-verification of its tool surface -- deliberate work with
# its own PR, not a pin bump. The ignore for mcp majors stays RETIRED so the
# release keeps arriving as a visible red PR rather than silence.
